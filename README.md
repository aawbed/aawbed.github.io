# Jermaine Otto Oyieri — Software Engineer Portfolio

A modern, high-performance personal developer portfolio showcasing production systems, applied machine learning pipelines, and IoT telemetry architectures.

## 🚀 Features

- **Modern Responsive Design:** Custom dark luxury developer theme built with semantic HTML5, modern CSS3 (custom properties & glassmorphism), and zero frontend framework overhead for instant page load.
- **Project Case Studies & Filtering:** Real-time categorical filtering across Full-Stack & ML, Web & UI, and IoT & Systems builds.
- **Integrated Terminal Shell (CLI Mode):** Interactive modal CLI terminal with command interpreter (`help`, `about`, `projects`, `skills`, `contact`, `hire`, `whoami`), history tracking, and keyboard shortcuts.
- **Copy-to-Clipboard Toast:** Instant email copying with visual user feedback.
- **100% Zero-Build:** Opens directly in any browser without needing `npm run build` or heavy tooling.

## 📁 Projects Featured

1. **KQ Sales & Order Intelligence System:** Machine Learning sales order platform with SARIMAX time-series demand forecasting (85% CI), Isolation Forest anomaly detection, K-Means RFM clustering, and automated ReportLab PDF invoicing for Kenya Airways operations.
2. **Earthpulse:** Real-time environmental and climate telemetry platform deployed on Vercel with serverless API integration.
3. **Interactive Terminal Dev Shell:** Developer portfolio CLI engine with CRT scanline styling deployed via GitHub Pages.
4. **Siwaka Street Eats:** Hyperlocal campus food ordering and vendor marketplace.
5. **Shamba Sense:** Precision agriculture telemetry platform streaming live sensor data from ESP32 edge units.
6. **Blockchain Ledger Explorer:** Vite + Tailwind CSS + Drizzle ORM transaction explorer.

## 💻 Local Preview

Open `index.html` directly in any web browser, or launch a quick local server:

\`\`\`bash
# Python
python -m http.server 3000

# or Node.js npx serve
npx serve .
\`\`\`

## 🌐 Deployment to GitHub Pages

To deploy this directly to your GitHub Pages (`https://aawbed.github.io`):

\`\`\`bash
git init
git add .
git commit -m "feat: initial commit of developer portfolio"
# create repo on GitHub: gh repo create aawbed.github.io --public --source=. --push
\`\`\`
